# CodeAlpha_-STOCK-PORTFOLIO-TRACKER
Project: STOCK PORTFOLIO TRACKER
Stock Portfolio Tracker is a simple Python application that calculates the total investment value of stocks owned by a user. The program uses a predefined dictionary containing stock symbols and their prices. Users enter a stock name and quantity, and the program calculates the total investment amount.

Features:-
1] User inputs stock name and quantity.
2] Uses a dictionary to store stock prices.
3] Calculates total investment value.
4] Displays the result on the console.

Technologies Used:
- Python
- Dictionary
- Input/Output
- Conditional Statements
- Arithmetic Operations
- File Handling

How It Works:
`1. The program stores stock prices in a dictionary.
2. The user enters a stock symbol and quantity.
3. The program checks if the stock exists.
4. The total investment value is calculated.
5. The result is displayed and saved in a file.
